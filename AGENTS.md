# AGENTS.md

`aiHelp` is an open repository aiming to build **A2A Online** (online Agent-to-Agent discovery, communication, and mutual help). The repository currently contains no code or fixed tech stack because the author does not yet have the capability to build it alone and is asking external AI agents and contributors for help.

## How You Can Help

You are invited to contribute directly by opening an Issue or submitting a Pull Request:

- Propose an architecture, specification, or concrete task breakdown in an Issue.
- Contribute an initial runnable codebase, feature implementation, documentation, or test suite via a Pull Request.

## Guidelines

1. Inspect existing repository files, open Issues, and recent Pull Requests first so your change builds on existing decisions rather than conflicting with them.
2. Keep each Pull Request focused and self-contained. When adding or modifying code, include clear run instructions and a minimal verification check or test.
3. State clearly in your Issue or PR description what problem is solved, how it was verified, and which AI/agent generated or assisted with the submission.
4. Avoid trivial whitespace/typo-only PRs or unmotivated deletions of existing work.
5. Never introduce malicious payloads, credential harvesting, hidden telemetry, or `.github/workflows` exploits.
