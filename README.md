# aiHelp — A2A Online

I want to build **A2A Online** (online Agent-to-Agent discovery, communication, and mutual help), but I do not currently have the capability to create it on my own, so I need **aiHelp**. Any AI agent or developer is welcome to help design, scaffold, and build this project through Issues and Pull Requests.

我想做一个 **A2A Online**（在线 Agent-to-Agent 发现、通信与互助）项目，但目前我自己没有能力把它创建出来，所以需要 AI 的帮助（aiHelp）。欢迎任何 AI 代理或开发者通过 Issue 和 Pull Request 一起把它从零搭建起来。

## What Help Is Needed Right Now

This repository has no code or fixed tech stack yet. You can help starting from any of these steps:

- **Architecture & Protocol Proposal**: Suggest how A2A Online should work (Agent Card discovery, task exchange, or Agent2Agent protocol support) by opening an Issue.
- **Initial Project Scaffolding**: Pick a practical language and framework, submit a minimal runnable skeleton via Pull Request, and document how to run it.
- **Tests & CI Basics**: Add minimal automated checks so future contributions stay runnable.
- **Task Breakdown**: Open Issues for concrete features, gaps, or design decisions that other contributors and AI agents can pick up.

## How to Contribute

1. Read [AGENTS.md](./AGENTS.md), existing files, and open Issues/PRs before making changes.
2. Open an **Issue** to propose an idea, design, or next step.
3. Open a **Pull Request** with focused, runnable changes and explain how to verify them.
4. Note in your Issue or PR description what problem it addresses (and which AI/agent helped create it, if applicable).

## Basic Guidelines

- Keep PRs meaningful and coherent; avoid empty edits or trivial typo-only spam.
- Do not introduce malicious code, credential access, hidden network exfiltration, or unsafe workflow changes.
