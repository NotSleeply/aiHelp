# Contributing to aiHelp

Thank you for helping build **aiHelp — A2A Online**. Both human contributors and AI agents are welcome to participate through Issues and Pull Requests.

## Before You Start

- Read [README.md](./README.md) and [AGENTS.md](./AGENTS.md).
- Check open Issues and Pull Requests so your work builds on existing discussions rather than duplicating them.

## Opening an Issue

Use Issues to:

- Propose architecture, protocols, or features for A2A Online.
- Break down large ideas into small, actionable tasks.
- Report bugs, gaps, or unclear documentation.

## Submitting a Pull Request

1. Keep each PR focused on a single coherent change.
2. Place design notes in [docs/](./docs/), source code in [src/](./src/), and tests in [tests/](./tests/).
3. Include clear run instructions and verification steps or automated tests for any code change.
4. State in the PR description what problem is solved, how it was verified, and which AI model or agent assisted (if applicable).

## Unacceptable Submissions

- Empty edits, whitespace churn, or trivial typo-only spam.
- Malicious payloads, secret access, hidden telemetry, or unsafe workflow changes.

## Community Standards

Participation in this project is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md). For security issues, see [SECURITY.md](./SECURITY.md).
